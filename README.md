# 📆 بوت حساب الستريك اليومي بلغة رستم (Rust Streak Bot)

<img width="1376" height="768" alt="image_5456d203" src="https://github.com/user-attachments/assets/44855f24-a30c-4ae2-bdcf-6473fbd40f11" />

بوت ديسكورد متطور وعالي الأداء مصمم بالكامل باستخدام لغة **Rust** وإطار العمل **Poise**. يتيح هذا البوت لأعضاء سيرفرك تحدي أنفسهم للحفاظ على نشاطهم اليومي (Streak) عبر تسجيل الدخول مرة واحدة كل يوم تقويمي، ويتميز بنظام تخزين محلي ذكي وخفيف يعتمد على ملفات JSON دون الحاجة لتعقيدات قواعد البيانات مثل MongoDB.

## ✨ المميزات الرئيسية
* **تخزين بدون قاعدة بيانات (No-Database JSON):** يتم حفظ كافة بيانات المستخدمين والستريك تلقائياً في ملف `streaks.json` محلي، مما يجعله سريعاً وخفيفاً جداً على موارد النظام ومثالياً للتشغيل على بيئات الموبايل مثل Termux.
* **نظام تجديد وتصفير ذكي (24h Reset):** يعتمد البوت على الأيام التقويمية الحقيقية (UTC). إذا قام المستخدم بتسجيل الدخول مرتين في نفس اليوم سيطلب منه الانتظار للغد، وإذا تخطى يوماً كاملاً دون تسجيل الدخول سيتم تصفير الستريك الخاص به تلقائياً (Reset) وإعادته لليوم الأول.
* **لوحة الصدارة المباشرة (`/leaderboard`):** يعرض الأمر أعلى 10 مستخدمين يمتلكون أطول سلسلة أيام نشاط بالسيرفر مرتبة تنازلياً مع إظهار ميداليات للمراكز الثلاثة الأولى.
* **التوقيت النسبي المباشر:** يعتمد البوت على صيغ ديسكورد الزمنية المتطورة لإظهار آخر وقت نشاط للمستخدم بشكل نسبي (مثال: *منذ 3 ساعات*) تماشياً مع التوقيت المحلي لجهاز كل عضو.
* **هجين بالكامل (Hybrid):** يدعم تنفيذ الأوامر عبر الأوامر المائلة `/` أو عبر البادئة التقليدية `!`.

---

## 🛠️ المتطلبات الأساسية
* بيئة عمل لغة رستم **Rust & Cargo** (الإصدار 2021 أو أحدث).
* تطبيق Termux (في حال تشغيله من الهاتف) أو أي نظام تشغيل آخر.
* رمز البوت (Bot Token) من لوحة تحكم المطورين [Discord Developer Portal](https://discord.com).

---

## 🚀 إعداد وتشغيل البوت

### 1. إعداد الرمز السري (Token)
قم بإنشاء ملف باسم `.env` في المجلد الرئيسي للمشروع (بجانب ملف `Cargo.toml`) أو غير اسم الملف `.env.example` وضع فيه التوكن الخاص بك باستخدام الأمر التالي في Termux:
```bash
nano .env
```
ثم أضف السطر التالي داخل الملف واحفظه:
```env
DISCORD_TOKEN=ضع_هنا_توكن_البوت_الخاص_بك
```

### 2. تفعيل صلاحيات الرسائل (Intents)
تأكد من الذهاب إلى صفحة البوت الخاص بك في موقع المطورين بديسكورد، ومن تبويب **Bot** قم بتفعيل خيار **Message Content Intent** لكي يتمكن البوت من قراءة أمر `!streak`.

### 3. تشغيل البوت

#### 📱 للتشغيل الآمن والخفيف داخل تطبيق Termux:
```bash
cargo run --release -j 1
```
*(استخدام أمر `-j 1` يضمن بناء حزم المشروع واحدة تلو الأخرى لتفادي استهلاك معالج الهاتف بشكل مفاجئ مما يمنع نظام أندرويد من إغلاق تطبيق Termux تلقائياً أثناء البناء).*

#### 💻 للتشغيل على الحاسوب الشخصي أو السيرفرات الخارجية (VPS):
```bash
cargo run --release
```

## 📜 الأوامر المتاحة داخل السيرفر
بمجرد تشغيل البوت ودخوله للسيرفر، يمكنك استخدام الأوامر التالية مباشرة:
* `/streak` أو `!streak` — لتسجيل الدخول اليومي وحفظ/تطوير سلسلة أيامك.
* `/leaderboard` أو `!leaderboard` — لاستعراض قائمة توب 10 لأعلى الأعضاء ستريك بالسيرفر.
